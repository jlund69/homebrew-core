## 2024-05-24 - Command Injection in GitHub Actions via Context Interpolation
**Vulnerability:** Command injection vulnerability in multiple GitHub Actions workflow files (`dispatch-build-bottle.yml`, `dispatch-rebottle.yml`, `publish-commit-bottles.yml`). User inputs from `github.event.inputs` were directly interpolated into bash shell commands using `${{ ... }}` syntax.
**Learning:** Direct interpolation of contexts like `${{ github.event.inputs.formula }}` into a `run` script creates a critical command injection flaw. If an attacker controls these inputs, they can insert shell metacharacters (e.g., `;`, `|`, `$()`) to execute arbitrary commands on the GitHub Actions runner.
**Prevention:** Always pass user-controlled input (like `github.event.inputs`, `github.event.pull_request.title`, etc.) into shell scripts as environment variables by defining them in an `env:` block. The shell script should then refer to the variable using the standard bash syntax (e.g., `$FORMULA`), which safely handles the content without evaluating it as shell commands.
