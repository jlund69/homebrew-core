## 2024-05-18 - GitHub Actions Command Injection via github.event.inputs
**Vulnerability:** User-controlled inputs from `github.event.inputs` (e.g. `args`, `pull_request`, `formula`) were being directly interpolated (`${{ }}`) into bash scripts in `run:` blocks within GitHub Action workflows. This allows an attacker to inject arbitrary shell commands if they can trigger a workflow dispatch or create a payload that influences the input variables.
**Learning:** GitHub Actions performs macro substitution on `${{ }}` variables before the shell processes the script. If the variable contains unescaped special shell characters (`;`, `|`, `$()`, etc.), the underlying shell will interpret them.
**Prevention:** Always map user-controlled GitHub contexts (like `github.event.inputs`, `github.head_ref`, etc.) into the step's `env:` block. The `run:` shell script should then refer to these values via shell environment variables (e.g., `$INPUT_ARGS`), bypassing GitHub Actions' macro substitution and avoiding shell injection vulnerabilities.
