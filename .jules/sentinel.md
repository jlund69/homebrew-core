## 2024-11-09 - GitHub Actions Command Injection via User Input
**Vulnerability:** Command injection vulnerability in multiple GitHub Actions workflow files (`dispatch-rebottle.yml`, `dispatch-build-bottle.yml`, `publish-commit-bottles.yml`). User inputs (e.g. `${{github.event.inputs.formula}}`, `${{github.event.inputs.args}}`) were being interpolated directly into shell scripts using string interpolation `${{ ... }}`.
**Learning:** Using direct string interpolation for user-controlled inputs in `run` blocks creates a shell command injection risk. If a malicious user provides input containing shell metacharacters like `;`, `&&`, or `$(...)`, they can execute arbitrary commands on the runner.
**Prevention:** Always pass user-controlled inputs (like `github.event.inputs`) into shell scripts using environment variables (the `env:` block) and reference them as `$ENV_VAR`. Keep optional multi-word arguments unquoted in bash to allow word splitting while still preventing execution of metacharacters.
